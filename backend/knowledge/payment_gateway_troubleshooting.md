# Payment Gateway Troubleshooting

## 1. Common Decline Codes
- Code 2001 (Insufficient Funds): Verify card balance.
- Code 2005 (3D Secure Failed): Ensure OTP from bank was entered correctly.
- Code 2010 (Fraud Trigger): Contact issuing bank to authorize international transaction.

## 2. Supported Payment Methods
We accept Visa, MasterCard, American Express, PayPal, and Apple Pay.
