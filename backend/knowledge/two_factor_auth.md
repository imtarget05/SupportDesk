# Two-Factor Authentication (2FA) Setup

## 1. Supported Authenticators
We support Google Authenticator, Authy, 1Password, and Microsoft Authenticator using standard TOTP protocol.

## 2. Emergency Backup Codes
When enabling 2FA, 10 one-time recovery codes are generated. Store them securely offline.
If you lose your device, support agents can reset 2FA only after identity verification.
